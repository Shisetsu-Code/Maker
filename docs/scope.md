# Maker: primera etapa

Editor visual del cliente y gestor local de plantillas. Plantillas declarativas versionadas, identidad y contenido separados del estilo. Materiales Plano, Glass y Metal. Vista previa de escritorio y celular. Importación de plantillas JSON, guardado local, proyecto portable y exportación HTML.

La demo no incluye autenticación, API de integración ni chat. Las cargas en el navegador son locales; el catálogo compartido se distribuye mediante archivos del repositorio.

Verificación: pruebas unitarias con Node y pruebas de navegador con Playwright, ejecutadas en GitHub Actions.
