# Maker — editor y catálogo de plantillas

## Alcance solicitado
Herramienta de administración para cargar plantillas y editor del cliente para crear su web. Referencia: interfaz del HAR aportado (barra segmentada, vista previa central, opciones de marca, compartir configuración). Implementación propia; nombres, identificadores, ilustraciones y contenido propios. No publicar el HAR, credenciales, recursos del proveedor ni endpoints originales.

## Diseño acordado en conversación
Plantilla = distribución; material = plano/glass/metal; marca y contenido independientes. Cambiar plantilla conserva todos los datos. Plantillas declarativas versionadas interpretadas por un motor común, no JavaScript/HTML/CSS de terceros. Cuatro distribuciones iniciales, tres materiales, vista escritorio/móvil. Carga JSON, duplicación, archivado local, exportación de catálogo. Edición de textos, logo raster, paleta, tipografía, radios, intensidad glass, orden/visibilidad de secciones. Deshacer/rehacer, guardado local, proyecto portable, enlace sin imágenes, HTML autocontenido.

## Límites explícitos
Etapa GitHub: aplicación estática sin servidor de aplicación. Administración local sin autenticación; no es una barrera de seguridad ni modifica otros navegadores. Catálogo compartido inicial en templates/catalog.json; se distribuye por commit o archivo. Proyectos guardados en este navegador, con aviso si el almacenamiento falla. No API, chat, pagos, cuentas, juegos operativos ni aprovisionamiento de dominios.

## Contratos
Formato maker-template-1: id, version (semver), name, description, layout (classic/sidebar/editorial/compact), hero (split/banner), columns (2..6), sections (IDs conocidos, únicos, hero obligatorio), materials (flat/glass/metal). Cambios visuales requieren nueva versión o duplicación. Proyectos incluyen snapshot de plantilla: archivar no rompe un borrador.
Formato maker-project-1: template, site (name/tagline/title/description/cta/sectionTitles/logo/heroImage), theme (material/accent/background/radius/blur/opacity/font), hidden y order (IDs conocidos). Esquemas estrictos, tamaño limitado, rechazo de propiedades desconocidas, protocolos peligrosos y prototipos. Rasters locales PNG/JPEG/WebP; SVG rechazado.

## Verificación
Pruebas Node: validación, límites, formatos futuros rechazados, aislamiento de contenido/tema, versionado independiente del orden de claves JSON, almacenamiento corrupto, XSS/exportación, Unicode y enlaces, undo/redo. Playwright Chromium: editor, importación/admin, cambio plantilla/material, persistencia, export HTML, portabilidad, enlaces, móvil sin overflow, todas las combinaciones. GitHub Actions ejecuta pruebas y publica capturas/trazas; despliegue Pages separado tras verificación exitosa de main.
