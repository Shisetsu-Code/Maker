# Maker Implementation Plan

> Execute inline, with tests before implementation and verification before completion.

**Goal:** Editor de sitios y gestor de plantillas comprobables en GitHub.
**Architecture:** Módulos JavaScript nativos sin dependencias de ejecución. Esquema estricto, catálogo versionado, renderer puro compartido por iframe/export, localStorage con errores visibles.
**Tech Stack:** HTML/CSS/JavaScript; Node test runner; Python Playwright para integración.
**Spec:** docs/superpowers/specs/2026-10-08-maker.md

## Global Constraints
No API/chat; no código de terceros dentro de plantillas; no HAR ni sesiones en repo; demo local claramente marcada; contenido preservado al cambiar plantilla; accesible por teclado.

## Review Focus
- Archivo malicioso o grande: rechazo antes de renderizar.
- Catálogo incompatible/corrupto: aviso, no reemplazo silencioso.
- Logo y Unicode al exportar/reimportar: preservación exacta.
- Navegador sin almacenamiento: editor usable con aviso y descarga.
- Cambiar plantilla/archivar: snapshot estable, sin pérdida de contenido.

## Tasks
1. tests/core.test.mjs y tests/storage.test.mjs → src/core.js, src/storage.js: RED, validar datos, estados/historial/versiones, GREEN.
2. tests/render.test.mjs → src/render.js, src/site.css: RED, renderer y HTML seguro, GREEN.
3. tests/browser.py → index.html, src/app.js, src/editor.css: editor, catálogo/admin, archivos/logo, responsive, errores visibles.
4. scripts/build.mjs + scripts/serve.mjs, workflows CI/Pages, README y formatos: ejecutar Node, navegador, capturas; publicar repo y verificar corrida real.

## Execution record
- Implementación aislada en /mnt/data/Maker, rama maker-initial; repositorio destino inicialmente sin aplicación.
- Ruling: módulos nativos, no React/build tool — sin dependencias de runtime, permite probar/publicar el editor estático tal como se sirve.
- Ruling: UI de administración local sin autenticación explícita — integración backend pospuesta por usuario. Catálogos compartidos mediante JSON/commit.
- Núcleo y renderer: pruebas RED observadas antes de implementar, luego GREEN. Regresión adicional de orden de claves JSON: RED, corrección de comparación semántica, GREEN.
- Navegación HTTP al servidor local bloqueada por política del entorno de trabajo. Se examinó la interfaz propia mediante carga offline de los mismos módulos y capturas Chromium; eso no sustituye el E2E HTTP. GitHub Actions ejecuta tests/browser.py con servidor real.
- Revisión visual: escritorio, material Glass, catálogo y celular; corregido el envío del formulario cuyo campo id ocultaba la propiedad DOM del formulario.
